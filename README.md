# AniSum

AniSum - веб-приложение для отслеживания прогресса просмотра аниме и получения кратких пересказов ранее просмотренных эпизодов с помощью AI.

## Какую проблему решает AniSum

При просмотре нескольких аниме одновременно или возвращении к сериалу после длительного перерыва бывает сложно вспомнить события предыдущих эпизодов, персонажей и важные детали сюжета.
Чтобы восстановить контекст, приходится пересматривать уже просмотренные серии или искать информацию в интернете, рискуя наткнуться на спойлеры.
AniSum решает эту проблему, предоставляя краткие AI-пересказы просмотренных эпизодов без раскрытия событий последующих серий.
Приложение также предусматривает синхронизацию истории просмотров с YummyAnime, чтобы пользователь мог быстро определить, на чём остановился, освежить в памяти сюжет и продолжить просмотр.
AniSum объединяет информацию об отслеживаемых аниме в удобной библиотеке, позволяя быстро оценить прогресс просмотра, ознакомиться с описаниями и выбрать, что посмотреть дальше, исходя из настроения и предпочтений.

## Планируемые возможности

- Каталог аниме и информация об эпизодах.
- Синхронизация истории просмотров с YummyAnime.
- Генерация кратких пересказов просмотренного контента с помощью LLM.
- Навигация по франшизам
- Карточка героев
- Синхронизация манги и ранобэ
